# Voicenotes

Свой аналог Otter / Fireflies / tl;dv: записывает встречи (вживую и онлайн-созвоны), расшифровывает речь с разметкой спикеров и собирает структурированный конспект: кратко, решения, задачи с ответственными и сроками, темы с таймкодами, открытые вопросы.

- **Расшифровка** — на выбор: OpenAI `gpt-4o-transcribe-diarize` или [Mistral Voxtral](https://mistral.ai) (французская компания, данные в ЕС). Обе понимают русский, немецкий, английский и размечают, кто говорит.
- **Конспект** — Claude (Anthropic) со структурированным ответом.
- **Интерфейс** — веб-приложение на русском; работает на компе и телефоне, ставится как приложение (PWA).

## Сколько стоит

За час встречи:

| | Расшифровка | Конспект (Claude Opus 5.5) | Итого |
|---|---|---|---|
| OpenAI | ~$0.36 | ~$0.20–0.25 | **~$0.55–0.60** |
| Mistral | ~$0.18 | ~$0.20–0.25 | **~$0.40** |

Модель выбирается в настройках приложения: по умолчанию Sonnet 5.5 (~$0.10 за час), можно Opus 5.5 (~$0.20) или Haiku 4.5 (~$0.05). Или выключи автоконспект и делай конспекты в Claude по подписке (см. ниже).

## Запуск на Mac без терминала

1. Поставь Node.js: https://nodejs.org → кнопка **LTS** → установщик.
2. Скачай проект (zip) и распакуй.
3. Дважды кликни `start.command`. Если macOS пишет «не удалось подтвердить, что файл не содержит вредоносного ПО», нажми «Готово» и сделай одно из двух:
   - в Терминале напечатай `bash ` (с пробелом), перетащи туда `start.command` и нажми Enter;
   - или «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть», потом снова двойной клик.
4. В первый раз откроется файл настроек `.env`: впиши ключи (см. ниже), сохрани, снова дважды кликни `start.command`.
5. Браузер откроется сам. Для онлайн-созвонов используй Chrome. Чтобы остановить — закрой окно терминала.

## Запуск на своём компьютере (терминал)

Нужен Node.js 20.12+ (лучше 22).

```bash
npm install
cp .env.example .env    # впиши ключи
npm start
```

Открой http://localhost:3000.

Ключи:
- для расшифровки **один из двух**: `OPENAI_API_KEY` — https://platform.openai.com/api-keys или `MISTRAL_API_KEY` — https://console.mistral.ai/api-keys
- `ANTHROPIC_API_KEY` — https://console.anthropic.com/settings/keys (нужно пополнить баланс в Billing; подписка Claude Pro/Max сюда не входит — API оплачивается отдельно)

ffmpeg ставится сам через npm (`ffmpeg-static`). Если не скачался, установи ffmpeg системно и укажи путь в `FFMPEG_PATH`.

## Как пользоваться

**Вживую** — пишет с микрофона. Положи телефон или ноутбук на стол.

**Онлайн-созвон** (только в десктопном Chrome/Edge) — пишет микрофон и звук созвона вместе:
- Meet / Zoom / Teams **в браузере**: выбери вкладку созвона и включи «Поделиться звуком вкладки».
- Zoom / Teams **приложением**: выбери «Весь экран» и включи «Поделиться системным звуком». На Windows это работает; на macOS — только в свежих версиях macOS и Chrome. Если такой галочки нет, открой созвон в браузере.
- Лучше в наушниках, чтобы звук из колонок не попадал в микрофон второй раз.

Потом жми стоп. Запись загрузится, через минуту-две появятся расшифровка и конспект.

Ещё:
- **Загрузить готовую запись** — диктофон с телефона, запись Zoom (m4a, mp3, mp4, wav, webm…).
- **Кто есть кто** (вкладка «Расшифровка») — Claude угадывает имена из разговора; поправь и нажми «Сохранить и пересобрать конспект».
- **Модель расшифровки** (Настройки → «Модель для расшифровки») — GPT Transcribe, текущая модель OpenAI, Voxtral через OpenRouter или напрямую через Mistral. Ключ `OPENROUTER_API_KEY` задаётся на сервере в `.env`; клиентам он не передаётся. Выбор общий для сайта и Mac, сохраняется на сервере и применяется к следующим загрузкам. Исходные файлы и старые расшифровки сохраняются. Voxtral через OpenRouter отдаёт таймкоды; разделение по говорящим в проверенном ответе отсутствовало. Записи отправляются частями по две минуты; новые модели получают FLAC из исходника вместо MP3 для плеера.
- **Настройки** (иконка справа сверху) — язык конспекта, язык встречи, глоссарий (имена, названия, термины — улучшают и распознавание, и конспект).
- **Заметки во время встречи** (как в Granola): пиши коротко по пунктам в поле под кнопкой записи — Claude раскроет каждый пункт подробностями из записи. Заметки можно дописать и потом на странице встречи («Мои заметки») и пересобрать конспект.
- Поле **«О чём встреча»** перед записью помогает Claude точнее понять контекст.
- Экспорт в Markdown: «Скопировать конспект» / «Скачать .md» (вместе с расшифровкой) — удобно вставлять в Notion, Obsidian, почту.

**Запись не теряется**: каждые 5 секунд кусок сохраняется в браузере (IndexedDB). Если вкладка закрылась, пропал интернет или упала загрузка, на главной появится «Незагруженная запись» с кнопкой «Загрузить». Можно записывать и без интернета, а загрузить потом.

## На свой сервер (VPS) — одной командой

Подходит для Ubuntu/Debian, в том числе если на сервере уже работает сайт: приложение встанет рядом на поддомен, существующие сайты установщик не трогает.

1. В панели, где куплен домен, добавь DNS-запись: тип **A**, имя **notes**, значение — **IP сервера**.
2. Зайди на сервер (`ssh root@IP_сервера`) и вставь:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/QuiltyVal/voicenotes/HEAD/install.sh | sudo bash
   ```
3. Ответь на вопросы: адрес (`notes.твойдомен`), ключи, пароль.

Установщик сам поставит Docker, найдёт nginx / Apache / Caddy и подключит к нему поддомен с HTTPS (если веб-сервера нет — поставит свой). Обновление — та же команда.

## Конспект по подписке Claude (MCP)

Приложение — MCP-сервер, его можно подключить к Claude (claude.ai, приложение на компе и телефоне):

1. В приложении: Настройки → «Конспект по подписке Claude» → «Копировать».
2. В Claude: Настройки → Коннекторы → «Добавить свой коннектор» → вставь адрес.
3. В чате: «сделай конспект последней встречи и сохрани» или «что мы решили с Борисом за сентябрь?».

Что Claude может: смотреть список встреч, читать расшифровки, искать по всем встречам, сохранять конспект обратно в приложение. Чтобы не платить за API дважды, выключи в настройках «Составлять конспект автоматически». Адрес коннектора содержит секретный ключ — не публикуй его.

## Программа для Мака (строка меню)

Значок в строке меню: «Начать запись» → пишется звук **всех** приложений (Zoom, Telegram, FaceTime, браузер…) и микрофон, без окна выбора экрана. «Остановить и отправить» → встреча откроется в приложении.

1. Открой Терминал и вставь:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/QuiltyVal/voicenotes/HEAD/mac/install.sh | bash
   ```
   Программа соберётся прямо на твоём Маке и встанет в «Программы». Если попросит поставить инструменты разработчика — согласись, дождись и вставь команду ещё раз.
2. Разреши микрофон и «Запись экрана и системного звука» (macOS спросит; если нет — Системные настройки → Конфиденциальность и безопасность → включи Voicenotes и перезапусти программу).
3. В меню значка → «Настройки…» → адрес приложения и пароль.

Нужна macOS 13 или новее.

## Расширение для Chrome

Записывает вкладку созвона (Meet, Zoom в браузере, Telegram Web…) и твой микрофон одной кнопкой на панели, без окна выбора вкладки. Работает и когда окно расширения закрыто (на значке горит REC).

1. Возьми папку `extension` из проекта (установщик для Мака кладёт её в «Документы» → «Voicenotes расширение Chrome»).
2. Открой `chrome://extensions`, включи «Режим разработчика» (справа сверху) → «Загрузить распакованное» → выбери папку.
3. Нажми на значок Voicenotes (закрепи его через «пазл») → ⚙︎ → адрес приложения и пароль → «Сохранить и проверить».
4. Один раз нажми «разреши микрофон», чтобы в запись попадал твой голос.

Дальше: открыл вкладку созвона → значок → «Записать эту вкладку» → «Остановить и отправить». Встреча откроется в приложении сама. Если отправка не удалась, запись не пропадает — в окне расширения будет «Повторить».

## С телефона

Браузеры дают доступ к микрофону только по HTTPS (или на `localhost`). Варианты:

1. **Сервер** (например, Hetzner, Германия, ~€4/мес) + домен:
   ```bash
   cp .env.example .env   # ключи, APP_PASSWORD, DOMAIN=notes.example.com
   docker compose up -d --build
   ```
   Caddy сам получит сертификат. Открой `https://твой-домен` на телефоне → «Добавить на главный экран».
2. **Tailscale**: `tailscale serve 3000` на компе — даёт HTTPS-адрес, доступный только твоим устройствам.

Если приложение доступно из сети, **обязательно задай `APP_PASSWORD`** — браузер спросит логин (любой) и пароль.

## Данные и GDPR

- Записи, расшифровки и конспекты лежат только у тебя: в папке `data/` (или в docker-томе). «Удалить встречу» стирает всё по ней.
- Аудио уходит на расшифровку: в Mistral — обрабатывается в ЕС; в OpenAI — по умолчанию в США (есть DPA; для проекта с хранением в ЕС укажи `OPENAI_BASE_URL=https://eu.api.openai.com/v1`, если OpenAI одобрил тебе EU-проект). Текст расшифровки уходит в Anthropic (США; есть DPA и стандартные договорные условия ЕС). Если нужно, чтобы всё оставалось в ЕС, Claude можно подключить через AWS Bedrock во Франкфурте — это небольшая доработка.
- В Германии записывать разговор без согласия участников нельзя (§201 StGB) — приложение напоминает об этом перед записью.

## Настройки `.env`

| Переменная | По умолчанию | Что это |
|---|---|---|
| `OPENAI_API_KEY` / `MISTRAL_API_KEY` | — | ключ для расшифровки (достаточно одного) |
| `TRANSCRIPTION_PROVIDER` | авто | `openai` или `mistral`; пусто — по заданному ключу |
| `OPENAI_TRANSCRIBE_MODEL` | `gpt-4o-transcribe-diarize` | модель OpenAI (без `diarize` — без разметки спикеров) |
| `ANTHROPIC_API_KEY` | — | ключ Anthropic |
| `APP_PASSWORD` | пусто | пароль на вход |
| `HOST` / `PORT` | `127.0.0.1` / `3000` | адрес сервера (`0.0.0.0` — доступ из сети) |
| `DATA_DIR` | `./data` | где хранить данные |
| `NOTES_LANGUAGE` | `ru` | язык конспекта по умолчанию: `ru`, `de`, `en`, `auto` |
| `CLAUDE_EFFORT` | `medium` | глубина размышлений: `low`, `medium`, `high` |
| `VOXTRAL_MODEL` | `voxtral-mini-2602` | модель Mistral |
| `FFMPEG_PATH` | авто | путь к ffmpeg |

## Как устроено

```
браузер (MediaRecorder, IndexedDB)
   │  POST /api/meetings  (аудиофайл)
   ▼
сервер Node/Express ── ffmpeg → mono mp3 16 кГц
   ├─ OpenAI или Voxtral: расшифровка + спикеры (S1, S2…) + таймкоды
   └─ Claude: структурированный JSON-конспект
data/meetings/<id>/  meeting.json · transcript.json · notes.json · audio.mp3
```

Встречи обрабатываются по очереди; если сервер перезапустился посреди обработки, она продолжится сама. Длинные записи режутся на части (OpenAI — по 20 минут, Mistral — по ~3 часа); чтобы спикеры не перепутались между частями, OpenAI получает образцы голосов из первой части.

Разработка: `npm run dev` (перезапуск при изменениях), `npm test`, `npm run typecheck`.
