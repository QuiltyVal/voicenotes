# Voicenotes

Свой аналог Otter / Fireflies / tl;dv: записывает встречи (вживую и онлайн-созвоны), расшифровывает речь с разметкой спикеров и собирает структурированный конспект: кратко, решения, задачи с ответственными и сроками, темы с таймкодами, открытые вопросы.

- **Расшифровка** — [Mistral Voxtral](https://mistral.ai) (французская компания, данные в ЕС), $0.003/мин, понимает русский, немецкий, английский и др., размечает, кто говорит.
- **Конспект** — Claude (Anthropic) со структурированным ответом.
- **Интерфейс** — веб-приложение на русском; работает на компе и телефоне, ставится как приложение (PWA).

## Сколько стоит

Примерно **$0.30–0.45 за час встречи**: Voxtral ~$0.18 + Claude Opus 5.5 ~$0.20–0.25. С `CLAUDE_MODEL=claude-sonnet-5-5` конспект примерно вдвое дешевле. 20 часовых встреч в месяц ≈ $6–9.

## Запуск на своём компьютере

Нужен Node.js 20.12+ (лучше 22).

```bash
npm install
cp .env.example .env    # впиши ключи
npm start
```

Открой http://localhost:3000.

Ключи:
- `MISTRAL_API_KEY` — https://console.mistral.ai/api-keys
- `ANTHROPIC_API_KEY` — https://console.anthropic.com/settings/keys

ffmpeg ставится сам через npm (`ffmpeg-static`). Если не скачался, установи ffmpeg системно и укажи путь в `FFMPEG_PATH`.

## Как пользоваться

**Вживую** — пишет с микрофона. Положи телефон или ноутбук на стол.

**Онлайн-созвон** (только в десктопном Chrome/Edge) — пишет микрофон и звук созвона вместе:
- Meet / Zoom / Teams **в браузере**: выбери вкладку созвона и включи «Поделиться звуком вкладки».
- Zoom / Teams **приложением**: выбери «Весь экран» и включи «Поделиться системным звуком». На Windows это работает; на macOS — только в свежих версиях macOS и Chrome. Если такой галочки нет, открой созвон в браузере.
- Лучше в наушниках, чтобы звук из колонок не попадал в микрофон второй раз.

Потом жми стоп. Запись загрузится, через минуту-две появятся расшифровка и конспект.

Ещё:
- **Загрузить готовую запись** — диктофон с телефона, запись Zoom (m4a, mp3, mp4, wav, webm…).
- **Кто есть кто** (вкладка «Расшифровка») — Claude угадывает имена из разговора; поправь и нажми «Сохранить и пересобрать конспект».
- **Настройки** (иконка справа сверху) — язык конспекта, язык встречи, глоссарий (имена, названия, термины — улучшают и распознавание, и конспект).
- Поле **«О чём встреча»** перед записью помогает Claude точнее понять контекст.
- Экспорт в Markdown: «Скопировать конспект» / «Скачать .md» (вместе с расшифровкой) — удобно вставлять в Notion, Obsidian, почту.

**Запись не теряется**: каждые 5 секунд кусок сохраняется в браузере (IndexedDB). Если вкладка закрылась, пропал интернет или упала загрузка, на главной появится «Незагруженная запись» с кнопкой «Загрузить». Можно записывать и без интернета, а загрузить потом.

## С телефона

Браузеры дают доступ к микрофону только по HTTPS (или на `localhost`). Варианты:

1. **Сервер** (например, Hetzner, Германия, ~€4/мес) + домен:
   ```bash
   cp .env.example .env   # ключи, APP_PASSWORD, DOMAIN=notes.example.com
   docker compose up -d --build
   ```
   Caddy сам получит сертификат. Открой `https://твой-домен` на телефоне → «Добавить на главный экран».
2. **Tailscale**: `tailscale serve 3000` на компе — даёт HTTPS-адрес, доступный только твоим устройствам.

Если приложение доступно из сети, **обязательно задай `APP_PASSWORD`** — браузер спросит логин (любой) и пароль.

## Данные и GDPR

- Записи, расшифровки и конспекты лежат только у тебя: в папке `data/` (или в docker-томе). «Удалить встречу» стирает всё по ней.
- Аудио уходит в Mistral (ЕС) для расшифровки. Текст расшифровки уходит в Anthropic (США; есть DPA и стандартные договорные условия ЕС). Если нужно, чтобы всё оставалось в ЕС, Claude можно подключить через AWS Bedrock во Франкфурте — это небольшая доработка.
- В Германии записывать разговор без согласия участников нельзя (§201 StGB) — приложение напоминает об этом перед записью.

## Настройки `.env`

| Переменная | По умолчанию | Что это |
|---|---|---|
| `MISTRAL_API_KEY` | — | ключ Mistral |
| `ANTHROPIC_API_KEY` | — | ключ Anthropic |
| `APP_PASSWORD` | пусто | пароль на вход |
| `HOST` / `PORT` | `127.0.0.1` / `3000` | адрес сервера (`0.0.0.0` — доступ из сети) |
| `DATA_DIR` | `./data` | где хранить данные |
| `NOTES_LANGUAGE` | `ru` | язык конспекта по умолчанию: `ru`, `de`, `en`, `auto` |
| `CLAUDE_MODEL` | `claude-opus-5-5` | модель для конспекта (`claude-sonnet-5-5` дешевле) |
| `CLAUDE_EFFORT` | `medium` | глубина размышлений: `low`, `medium`, `high` |
| `VOXTRAL_MODEL` | `voxtral-mini-2602` | модель расшифровки |
| `FFMPEG_PATH` | авто | путь к ffmpeg |

## Как устроено

```
браузер (MediaRecorder, IndexedDB)
   │  POST /api/meetings  (аудиофайл)
   ▼
сервер Node/Express ── ffmpeg → mono mp3 16 кГц
   ├─ Voxtral: расшифровка + спикеры (S1, S2…) + таймкоды
   └─ Claude: структурированный JSON-конспект
data/meetings/<id>/  meeting.json · transcript.json · notes.json · audio.mp3
```

Встречи обрабатываются по очереди; если сервер перезапустился посреди обработки, она продолжится сама. Записи длиннее ~3 часов режутся на части.

Разработка: `npm run dev` (перезапуск при изменениях), `npm test`, `npm run typecheck`.
